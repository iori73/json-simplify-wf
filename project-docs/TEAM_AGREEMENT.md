## Roles & Responsibilities

### Ankur Singh - Project Lead / Engineer

**Owns:**
- Technical architecture and implementation decisions
- Code quality, security, and infrastructure
- Roadmap and feature prioritization
- GitHub repository management (Issues, PRs, releases)
- Production deployment and monitoring

**Expected to:**
- Drive the project forward with clear milestones
- Create and manage GitHub Issues for tracking work
- Make final decisions on technical direction
- Communicate progress and blockers via text (Discord/GitHub)

### Iori - UI/UX Advisor

**Can help with:**
- UI/UX design feedback and suggestions
- User experience review and testing
- Visual design direction (colors, layout, themes)
- Documentation and copywriting review

**Cannot help with:**
- Backend development or infrastructure
- Security implementation
- Code architecture decisions
- DevOps, CI/CD, or deployment
- Leading feature implementation

**Important Note:**
Iori is not a software engineer. Technical decisions and implementation should not depend on Iori's input. When in doubt, Ankur should make the call or consult other engineers.

---

## Communication Guidelines

### Preferred Channels

| Channel | Use For |
|---------|---------|
| Discord (Text) | Quick questions, updates, casual discussion |
| GitHub Issues | Feature requests, bug reports, task tracking |
| GitHub PRs | Code review, implementation discussion |

### Communication Style

- **Async-first**: No expectation of immediate replies
- **Text-based**: Live meetings (Google Meet, calls) are not available
- **Structured**: Use GitHub Issues instead of long chat threads

### Response Time Expectations

- No SLA or guaranteed response time
- Both members have other commitments
- Patience and understanding are expected

---

## Decision-Making Process

| Decision Type | Who Decides |
|---------------|-------------|
| Technical architecture | Ankur |
| Feature prioritization | Ankur |
| UI/UX direction | Ankur (with Iori's feedback) |
| Domain name / branding | Ankur |
| Release timing | Ankur |

**Principle:** Ankur leads, Iori advises. Final call is always Ankur's.

---

## What This Agreement Prevents

- Scope creep on Iori's role (e.g., being asked to implement features)
- Expectation of live meetings or real-time availability
- Ambiguity about who owns decisions
- Chat-driven development without structured tracking
